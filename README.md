# caobamx-backend
Proyecto de Backend, aplicación para Integradoora 2.                                                                                      
Instrucciones actividad:
1. Crea una aplicación web que cuente con los siguientes formularios que permitan:
a) Creación de un usuario
b) Inicio de sesión
c) Subida de un archivo
2. Configura esta aplicación para que cuando un usuario válido inicie sesión tenga acceso a un panel de control donde pueda administrar los archivos que ha subido (ver, agregar, borrar).
